# 抖音发布与数据闭环

> 记录日期：2026-11-10
> 适用场景：个人抖音号，本地单机使用，不接入任何需要企业资质的开放平台应用。

## 为什么不做自动发布

抖音目前没有面向个人创作者的公开「发布视频 + 读取作品数据」接口：

- 抖音开放平台的视频发布能力需要企业/机构资质、应用审核和权限申请，个人号通常拿不到。
- 模拟登录、逆向签名、浏览器自动化发布都违反平台规则，账号有封禁风险，也会让工作台变成需要长期对抗风控的维护负担。

所以本项目的定位是：**发布动作仍在抖音里完成，工作台负责发布前后的记录与复盘**。

## 闭环流程

```
热点中心 / 选题池
      ↓
AI 脚本 → 剧情画布 → 剪映草稿
      ↓
抖音 App / 创作服务平台 手动发布
      ↓
发布台账：记录链接、标题、话题、关联选题/脚本
      ↓
数据回填：播放、点赞、评论、分享、收藏、涨粉
      ↓
Dashboard：近 30 天发布量、累计/平均播放、最佳作品
```

### 1. 发布前：生成发布文案

- 脚本管理每条脚本都有「记录发布」按钮，跳到发布台账并自动带上脚本、选题、画布。
- 发布台账支持保存「发布文案」和「话题标签」，一键复制后粘贴到抖音发布页。
- 视频仍通过「剧情画布 → 导出剪映草稿」生成，在剪映里检查后导出成片。

### 2. 发布后：登记一条发布记录

字段：

| 字段                   | 说明                                 |
| ---------------------- | ------------------------------------ |
| 标题                   | 抖音作品标题，必填                   |
| 链接                   | 抖音分享链接，可后补；用于打开原视频 |
| 发布时间               | 默认当前时间，可改                   |
| 发布文案               | 复制到抖音的标题/正文                |
| 话题标签               | `#标签1 #标签2`                      |
| 关联选题 / 脚本 / 画布 | 用于把数据和内容生产链对上           |
| 备注                   | 发布时的特殊说明                     |

保存后如果关联了选题，选题状态会自动从「待评估/在写/已写」推进到「已发」；「放弃」不会被覆盖。

### 3. 数据回填

抖音创作者中心能看到播放、点赞、评论、分享、收藏、涨粉等数据，但个人号没有稳定可用的数据导出接口，因此采用手动回填：

- 同一条发布、同一天只保留一条快照，重复保存会覆盖。
- 数字填平台显示的**累计值**，不需要自己算增量。
- 可以隔几天补一次，趋势图会取「当天及以前最新的一条快照」汇总。
- 历史快照保留在 `publication_stats`，后续如果接入官方接口，只需往同一张表写数据。

为了避免一条条手填，发布台账提供两种快捷方式：

1. **单条快捷粘贴**：点某条发布的「数据」，在快捷粘贴框里贴入
   `播放 1.2万 点赞 345 评论 12 分享 3 收藏 4 涨粉 5`，或者直接贴 6 个数字，自动填进表单。
2. **批量回填**：工具栏「批量回填」，从创作者中心或 Excel 复制多行，按
   `标题<TAB>播放<TAB>点赞<TAB>评论<TAB>分享<TAB>收藏<TAB>涨粉` 粘贴；带表头时会按「播放/点赞/评论…」列名取值。
   解析后先预览匹配结果，只写入已匹配台账标题的行，未匹配的行会标红并说明原因。

标题匹配先按完全一致，再忽略空格/标点后比较；台账里出现同名标题时不会自动写入，避免数据写错人。

## 数据模型

```sql
publications
  id, title, platform('douyin'), url, caption, tags, published_at, note,
  topic_id, script_id, project_id, created_at, updated_at

publication_stats
  id, publication_id, stat_date,
  views, likes, comments, shares, favorites, followers,
  note, created_at,
  UNIQUE(publication_id, stat_date)
```

## 接口

| 方法   | 路径                                | 说明                                          |
| ------ | ----------------------------------- | --------------------------------------------- |
| GET    | `/api/publish/list?platform=douyin` | 发布列表 + 最新一条数据                       |
| GET    | `/api/publish/summary?days=30`      | 发布量、累计/平均播放、最佳作品、近 14 天趋势 |
| POST   | `/api/publish`                      | 新增发布记录                                  |
| PUT    | `/api/publish/:id`                  | 编辑发布记录                                  |
| DELETE | `/api/publish/:id`                  | 删除记录及其数据                              |
| GET    | `/api/publish/:id/stats`            | 某条发布的数据历史                            |
| POST   | `/api/publish/:id/stats`            | 回填某一天的数据（按天 upsert）               |
| POST   | `/api/publish/stats/batch`          | 批量回填多条发布同一天的数据                  |
| DELETE | `/api/publish/:id/stats/:statId`    | 删除某天数据                                  |

## 以后要接官方接口时

预留的扩展点：

1. 新增 `server/publish/douyin.js`，实现 `publish(video, meta)` 与 `fetchStats(publication)` 两个函数。
2. 在 `publications` 增加 `external_id`（抖音作品 id）和 `sync_status`。
3. 定时任务调用 `fetchStats`，写 `publication_stats`，前端无需改动。
4. 只有在拿到正式开放平台权限后再启用，默认关闭；绝不使用模拟登录。

## 验收标准

- 从脚本页点「记录发布」，表单自动带出脚本、选题、画布。
- 新增一条发布后，Dashboard 的近 30 天发布数 +1。
- 回填当天数据后，列表「最新数据」和 Dashboard 累计播放同步更新。
- 同一天重复保存不会产生重复行；删除发布时数据一起删除。
